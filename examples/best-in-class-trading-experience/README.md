# Best-in-class trading experience

This is a historical worked example built from real Zerion product work. The product problems, decisions, JTBDs, scope, requirements, open questions, and proposed success measures are preserved. Personal names, private workspace links, and claims that were not supported by post-release evidence are omitted.

It is intentionally a set of normal product documents, not a tutorial or a test fixture:

- [Initiative: Best-in-class trading experience](product/initiatives/best-in-class-trading-experience.md)
- [PRD: Cross-chain Swap](product/prds/cross-chain-swap.md)

- [PRD: Transaction Toasters](product/prds/transaction-toasters.md)
- [PRD: Bridge Progress Tracking](product/prds/bridge-progress-tracking.md)

The example is honest about incomplete evidence. Proposed metrics and targets remain proposed where the source material did not contain a verified baseline or outcome result.

The source snapshot came from the March 9–April 26, 2026 planning cycle. The captured PRDs were draft/discovery documents; this example preserves the decisions being proposed at that point and does not imply that every item shipped or produced a verified outcome.
